# Laboratorios de Sistemas Distribuidos

Laboratorios del curso de Sistemas Distribuidos de la UNSA (mayo a julio de 2025), todos en Java. Algunos los hicimos en grupo con [kevinPedroYare](https://github.com/kevinPedroYare).

| Lab | Tema | Qué hay |
|---|---|---|
| [lab04-sd](lab04-sd) | RMI | Calculadora remota resuelta, un servidor de stock de medicinas y una biblioteca con cliente gráfico (`propuesto2_final`) |
| [lab05-sd](lab05-sd) | XML | Validación de documentos con DOM y con SAX (Xerces) |
| [lab06-sd](lab06-sd) | Servicios REST | Compra de productos con JAX-RS y un servlet de login, sobre GlassFish |
| [lab07-sd](lab07-sd) | Servicios SOAP | Servicio web de ventas publicado con JAX-WS |
| [lab08-sd](lab08-sd) | JDBC | Ventanas en Swing conectadas a MySQL |
| [lab09-sd](lab09-sd) | Transacciones | `commit` y `rollback` con JDBC, y un login en Swing con patrón DAO |

Cada carpeta tiene sus instrucciones de compilación cuando hacen falta. Los labs con base de datos usan el conector de MySQL que está en su carpeta `lib/`.
